# Swedish Driving Platform — Technical Documentation

This directory contains the technical documentation, architectural specifications, database designs, API schemas, and architecture decision records (ADRs) for the Swedish Driving Platform.

## Directory Structure

- **`architecture/`**: System architecture, component diagrams, modular monolith structure, data flow, and Master SRS (`Swedish_Driving_Platform_Master_SRS_Gothenburg_Dynamics.docx`).
- **`requirements/`**: Feature requirements, acceptance criteria, user stories, and scope control documentation for Phase 1 and Phase 2.
- **`database/`**: Database entity schemas, relationship models, indexing strategies, and migration guides.
- **`api/`**: REST API contracts, request/response formats, error codes, and OpenAPI/Swagger specifications.
- **`decisions/`**: Architecture Decision Records (ADRs) documenting major technical decisions, tradeoffs, and rationale.
